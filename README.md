# بسام (Bassam)

لعبة ركض وقفز (Platformer) عراقية الهوية، بطلها **بسام** بشماغه وعقاله. اللعبة تحتوي على **100 مرحلة** موزعة على **10 عوالم** مستوحاة من مدن وحضارات عراقية: بابل، أور، الأهوار، بغداد، البصرة، سامراء، أربيل، الحضر، السليمانية، والموصل — في نهاية كل عالم زعيم (Boss). صُنع بالكامل بتقنيات ويب (HTML5 Canvas + JavaScript خالص، بدون أي مكتبة رسوميات خارجية)، ومهيّأ للتحويل مباشرة إلى ملف APK عبر GitHub Actions.

**الإصدار الحالي: 1.0.2**

## أبرز الميزات
- **ثنائية اللغة بالكامل**: عند أول تشغيل يختار اللاعب العربية أو الإنجليزية؛ يمكن تغييرها لاحقاً من الإعدادات. كل نصوص الواجهة، القصة، وتلميحات المراحل تُترجم فوراً.
- **قصة قصيرة** تُعرض قبل بدء اللعب أول مرة (ويمكن إعادة قراءتها لاحقاً من زر «القصة» في القائمة)، مع ملخص طريقة اللعب أسفلها.
- **متجر أزياء** (🪙): كل دينار يُجمع أثناء اللعب يُضاف لمحفظة دائمة، تُستخدم لشراء أزياء جديدة للشخصية (5 أزياء) تُطبَّق فوراً على الشخصية في كل مكان (القائمة، اللعب، المعاينة).
- **حفظ تلقائي كامل ودائم**: التقدم (المراحل المفتوحة، النجوم، المحفظة، الأزياء المملوكة والمفعّل، اللغة، الإعدادات) يُحفظ محلياً على الجهاز ويبقى محفوظاً حتى بعد إغلاق التطبيق وإعادة فتحه.
- **زرّا بدء وخروج واضحان** في القائمة الرئيسية: «ابدأ اللعب» و«خروج» (مع تأكيد قبل الخروج).

## طريقة اللعب
- **◀ / ▶**: الحركة يمين ويسار (سهما لوحة المفاتيح أو الشاشة اللمسية).
- **قفز**: مسافة (Space) أو زر «قفز». كل ما ضغطته أطول كانت القفزة أعلى.
- **دحرجة**: Shift أو زر «دحرجة» — أثناء الركض تتحول لكرة سريعة تهاجم الأعداء، ووأنت واقف تثبيتها ثم تركها يطلقك بسرعة (Spin Dash).
- الأشواك لا تُقتل بالدحرجة، فقط بالقفز فوقها.
- الدنانير تحميك من فقدان محاولة عند الإصابة الأولى، وكل ما تجمعه يُضاف لمحفظتك الدائمة لشراء أزياء من المتجر.
- 3 محاولات لكل مرحلة، وتقييم بالنجوم (١-٣) حسب الزمن ونسبة الدنانير المجموعة وعدد مرات الموت.

## هيكلة المشروع
```
www/                 كل ملفات اللعبة (HTML/CSS/JS) — هذا ما يُعبَّأ داخل تطبيق الأندرويد
  i18n.js            كل نصوص الواجهة بالعربي والإنجليزي + أداة التبديل بينهما
  shop.js            تعريف الأزياء القابلة للشراء وألوانها
  engine.js          محرك اللعبة الصرف (فيزياء، توليد المراحل، الأعداء، الزعماء) — بلا رسم أو DOM
  render.js          كل الرسم (خلفيات، أرض، شخصية بأزيائها، أعداء، HUD) على Canvas
  audio.js           كل الأصوات مولّدة برمجياً عبر WebAudio (بدون ملفات صوت خارجية)
  game.js            اللغة، القصة، الشاشات، المتجر، التحكم، الحفظ الدائم، الحلقة الرئيسية
  index.html / style.css / manifest.json / sw.js / privacy.html
  icons/             أيقونات التطبيق بجميع المقاسات (مولّدة برمجياً)
resources/           icon.png و splash.png المصدر لتوليد أيقونة وشاشة بدء تطبيق الأندرويد
tools/               سكربتات اختبار ومساعدة (اختبار المحرك، اختبار المتصفح، توليد الأيقونات)
.github/workflows/   أتمتة بناء APK عبر GitHub Actions
capacitor.config.json / package.json   إعداد Capacitor لتحويل الويب إلى تطبيق أندرويد حقيقي
```

## تشغيل اللعبة محلياً للتجربة
```bash
cd www
python3 -m http.server 8000
# افتح المتصفح على http://localhost:8000
```

## تحويل المشروع إلى ملف APK
### الطريقة الأسهل: GitHub Actions (تلقائي بالكامل)
1. ارفع هذا المستودع كما هو إلى GitHub.
2. تبويب **Actions** يبني APK تلقائياً عند كل Push إلى `main`. حمّل **bassam-debug** من قسم Artifacts.
3. لإصدار **APK موقّع**: أنشئ وسماً بصيغة `v1.0.2` وادفعه:
   ```bash
   git tag v1.0.2
   git push origin v1.0.2
   ```
   سيُبنى إصدار Release ويُرفع تلقائياً كملف على صفحة الإصدار في GitHub.

### توقيع الإصدار (مطلوب لمتاجر مثل Google Play)
أضف هذه الأسرار في إعدادات المستودع (Settings → Secrets and variables → Actions):

| الاسم | الوصف |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | ملف الـ keystore مُرمّز base64 (`base64 -w0 my.keystore`) |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة مرور الـ keystore |
| `ANDROID_KEY_ALIAS` | اسم المفتاح |
| `ANDROID_KEY_PASSWORD` | كلمة مرور المفتاح |

بدونها يُبنى إصدار غير موقّع تلقائياً (صالح للتجربة فقط).

### زر «خروج» على أندرويد
أضفنا `@capacitor/app` إلى `package.json`؛ عند تشغيل `npx cap sync` سيُضاف تلقائياً إلى مشروع الأندرويد، فيعمل زر «خروج» داخل اللعبة على إغلاق التطبيق فعلياً على الجهاز. داخل المتصفح، يحاول الزر إغلاق التبويب، وإن تعذّر يعرض رسالة توجّه المستخدم لاستخدام زر الرجوع.

### البناء يدوياً
```bash
npm install
npx cap add android
npx @capacitor/assets generate --android
npx cap sync android
cd android
./gradlew assembleDebug
```

## الحفظ الدائم
كل بيانات اللاعب (المراحل، النجوم، المحفظة، الأزياء، اللغة المختارة، الإعدادات) تُخزَّن عبر `localStorage` على الجهاز نفسه — وهذا يعمل تلقائياً داخل تطبيق أندرويد المبني بـ Capacitor تماماً كما في المتصفح، وتبقى البيانات محفوظة بعد إغلاق التطبيق بالكامل وإعادة فتحه، ولا تُمسح إلا إذا مسح المستخدم بيانات التطبيق يدوياً أو ضغط «مسح كل التقدم» من الإعدادات.
